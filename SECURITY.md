# Security policy

Please report security vulnerabilities privately rather than opening a public issue.

Use the [GitHub private vulnerability reporting form](https://github.com/radiantfalcon/OpenTunes/security/advisories/new) when it is available for this repository. If private reporting is unavailable, contact the maintainers through GitHub and avoid sharing exploit details publicly.

Include the affected version, platform, impact, and steps needed to reproduce the issue. Do not include real credentials, personal data, or other secrets in a report.

Security reports are reviewed by the maintainers; please allow time for investigation and a coordinated fix before publicly disclosing the issue.
